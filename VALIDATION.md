## Practical limits

- Browser QA used installed desktop Google Chrome with responsive viewports;
  Safari, Firefox and physical mobile devices were not tested.
- Automated accessibility checks are not a complete screen-reader audit.
- Images above 4 MP are resized; 15 MiB file and 50 MP decoded-source limits apply.
- The bundled 10.9 MB runtime has an initial load cost. Low-memory devices may
  require smaller uploads. Decoding occurs before dimension checks.
- Browser and Python file decoding can differ. Exact numerical comparisons use
  the same decoded pixels. Y-mode histograms describe the working Y plane.
- Link configuration requires the user's actual URLs. Empty links open settings.
- A live Pages URL is not available until the user publishes this standalone
  project in their own repository. No remote publishing was attempted.
